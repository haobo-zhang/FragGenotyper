# Source distribution for FragGenotyper 1.8.3

The release tag contains runnable Python source, tests and text examples. For building a packaged application or viewing PNG/PDF examples, use the complete source ZIP attached to release v1.8.3, which includes the build icon and illustrations. The build icon is also included on the main branch in this directory.

Scientific source files have not changed during publication. See README.md for dependencies, supported inputs, tests and platform limitations. verification.json and regression_tests.log record prior validation, and the release manifest identifies package checksums and the tag commit.
